# Rules for working on this site (read first)

## The history of this repository was rewritten on 2026-10-21
- Always start from a FRESH clone of `main` (`git clone` again). Do not reuse an older local copy.
- Never merge, rebase, cherry-pick or push from a clone made before 2026-10-21 — it carries files that were deliberately removed.
- Never force-push. If a push is rejected as non-fast-forward, stop and ask the owner; do not "fix" it with pull/merge from an old copy.

## Content that must never be (re)added
- COSMOS: key-visual drafts, photocards, space proposals (zone design/site pairs), floor plans, staff passes, promo-event poster, Instagram insight figures (total views, interactions, per-post views).
- DDDM: artist retouch before/after photos.
- MUSE.D: only the cover + two inner spreads per issue, at 480px page width with the watermark. Never add full-issue or high-resolution pages.
- Do not use photos from the owner's folders without asking. Treat anything BIGBANG-related as sensitive: only officially released material.
